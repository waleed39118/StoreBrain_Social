# OmniRoute

مجلد مستقل لتشغيل **OmniRoute** — غير مدمج مع StoreBrain_Social ولا يعتمد عليه أي جزء منه.

- المصدر الرسمي: <https://github.com/cheaper-inference/OmniRoute>
- الرخصة: MIT
- النسخة المثبّتة هنا: `3.8.54` (صورة Docker: `diegosouzapw/omniroute`)

## ما هو؟
بوابة (Gateway) تعرض عنوان API واحداً متوافقاً مع OpenAI، وتوزّع الطلبات على مزوّدين كثيرين
لنماذج الذكاء الاصطناعي مع انتقال تلقائي عند الفشل، ومعها لوحة تحكم ويب.

## لماذا لا يُحفظ الكود المصدري هنا؟
المشروع ضخم (حوالي 29 ألف ملف). نسخه داخل هذا المستودع يضخّمه ويجعل تحديثه صعباً.
لذلك يُشغَّل من صورة Docker الرسمية بنسخة مثبّتة.

## التشغيل
المتطلبات: Docker و Docker Compose.

```bash
cd OmniRoute
cp .env.example .env
```

املأ `JWT_SECRET` و `API_KEY_SECRET` في `.env`:

```bash
openssl rand -base64 48
```

```bash
openssl rand -hex 32
```

ثم:

```bash
docker compose up -d
```

افتح لوحة التحكم: <http://127.0.0.1:20128>

الإيقاف:

```bash
docker compose down
```

## إعدادات الأمان المطبّقة في `docker-compose.yml`
| الإعداد | السبب |
| --- | --- |
| الربط على `127.0.0.1` فقط | اللوحة والـ API لا تظهر لأي جهاز آخر على الشبكة |
| نسخة مثبّتة بدل `latest` | لا تتغير النسخة دون علمك |
| `cap_drop: ALL` و `no-new-privileges` | الحاوية بلا صلاحيات نظام إضافية |
| تشغيل داخل Docker | ميزة MITM لا تستطيع تثبيت شهادة جذرية أو تعديل `/etc/hosts` على جهازك |

## ⚠️ تحذيرات — اقرأها قبل الاستخدام
1. **لا تفعّل وضع MITM** على جهازك مباشرة (خارج Docker). يثبّت شهادة جذرية في النظام
   ويعدّل `/etc/hosts` بصلاحيات `sudo`، ما يسمح بفك تشفير حركة الشبكة.
2. **تجنّب "الموديلات المجانية" المعتمدة على انتحال هوية أدوات أخرى** أو إعادة استخدام توكنات
   الاشتراكات. تخالف شروط المزوّدين وقد تؤدي لحظر حساباتك، وقد تتوقف في أي لحظة.
   استخدم مفاتيح API رسمية من حساباتك.
3. **كل الطلبات ومفاتيح API تمر عبر هذه البوابة.** لا تكشفها على الإنترنت، ولا تستخدم نسخاً
   منسوخة من مستودعات غير رسمية (مثل `free_omiroute`).
4. لا ترفع ملف `.env` إلى git (مستثنى في `.gitignore`).

## التحديث
1. راجع `CHANGELOG.md` في المستودع الرسمي.
2. غيّر رقم النسخة في `docker-compose.yml`.
3. نفّذ:

```bash
docker compose pull && docker compose up -d
```
